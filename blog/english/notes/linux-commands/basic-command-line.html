1.Linux Command Line

To learn the fundamentals of the command line, navigating files, directories, and more.

Source: linuxjourney



$ echo Hello World

$ echo “Hello World”

$ echo $USER



$ pwd

  • Print Working Directory



$ cd

  • Change Directory

  • Absolute path: starting from root directory (starts with \)

  • Relative path: relative to current location

$ cd .

  • current directory

$ cd ..

  • parent directory

$ cd ~

  • home directory

$ cd -

  • previous directory



$ ls

  • List Directory

$ ls <path>

$ ls -a

  • to view hidden files

$ ls -l

  • to view detailed information in long format

  • the detailed information are as follows: file permissions, no of links, owner name, owner group, file size, time-stamp of last modification, file/directory name

$ ls -r

  • to view in reverse alphabetical order

$ ls -la

  • to combine to flags



$ touch <file_names>

  • primary purpose: to update the access and modification file time-stamps of a file or directories.

  • If a file does not exist, it will create the file

$ touch -r <reference_file_name> <destination_file_name>

  • to set the destination file’s time-stamp to match that of another reference file

$ touch -d “2026-04-12 23:35:00” <file_name>

  • to set a file’s time-stamp to a specific date and time



$ file <file_name>

  • to find out what kind of a file a file is



$ cat <file_name>

  • basic use: to display the content of a single file directly in your terminal

$ cat <file_1> <file_2>

  • can combine, or concatenate multiple files and display their combined output

$ cat > file_name

  • to write text into a file directly from your terminal. Note: This also create a file if not exist

  • use ctrl+d to save and exit the text

$ cat -n file_name

  • it will numbers all output lines, starting from 1

$ cat -b file_name

  • it will numbers only the non-empty output lines



$ less <file_path>

  • to view a text file in page format

  • Arrow keys and Page keys to navigate

  • g : to move directly to the beginning of the text file

  • SHIFT+g or G: to jump to the end of the text file

  • h : to display helpful summary

  • q : to exit

  • /search_term : to search forward for “search_term”

  • ?search_term : to search backword for “search_term”

  • n : to jumps to the next occurrence of the search term

  • N : to jumps to the previous occurrence



$ history

  • to see list of commands you have used

  • up arrow : to cycle backward through your history

  • !! : to execute the most recent command again

  • CTRL+r : to initiate reverse search in history

$ history -c

  • to clear command history for your current session

$ history -w

  • to save the current session’s history to your history file

$ history -d <offset>

  • offset is the number shown next to the command in ‘history’ output

$ clear

  • to clear terminal screen



$ cp [source] [destination]

  • to copy files and directories

$ cp <file> <destination_path/new_file_name>

  • to copy a file and give it a new name in destination

  • * : matches any sequence of characters

  • ? : matches any single character

  • [] : matches any one of the characters enclosed in the brackets

$ cp -r folder/ /home/user/Documents

  • to copy a directory and all of its contents

$ cp -i file /home/user/Documents

  • Note: by default cp will overwrite a file at the destination if it has the same name.

  • to prevent accidental data loss, use the -i (interactive) flag, which prompts for confirmation before overwriting

$ cp -f file /home/user/Documents

  • to force an overwrite without any prompts

$ cp -p file /home/user/Backup

  • Note: when you copy a file, its meta data, such as modification time and ownership, is typically updated.

  • to preserve these original attributes, the flag -p is essential.



$ mv [source] [destination]

  • to move files and directories

$ mv old_file_name new_file_name

  • to rename files and directories

$ mv file1 file2 file3 destination/

  • to move multiple files at once

$ mv -t /destination file1 file2 file3

  • to specify target directory first and then the source files to move

  • Note: mv directly moves all subdirectories of a folder without any flags

$ mv -i source_file destination_directory

  • Note: by default mv will overwrite if same file name is present in destination folder

  • the flag -i (interactive) will prompt you for confirmation before overwriting existing data

$ mv -b file1 directory_with_file1

  • if you intend to overwrite a file but want to keep the old version, this will create a backup of the destination file and the backup is typically renamed with a tilde (~) suffix

$ mv -v file1 file2 /somedirectory

  • this option makes the command to print out what it is doing, showing each file being moved or renamed



$ mkdir directory1 directory2

  • make directory

$ mkdir -p dir1/dir2/folder

  • to create a directory and also its parent directories (if not exist), the flag -p is used



$ rm file1

  • to remove or delete a files

$ rm -f file1

  • to remove all specified files without prompting even if they are write-protected

$ rm -r directory

  • to remove recursively delete the directory

$ rmdir directory

  • to remove an empty directory



$ find [path] [expression]

  • to search or find files in a path

$ find /home -name puppies.jpg

  • to search for a file named ‘puppies.jpg’ within the /home directory and all its subdirectories

$ find /home -type d -name MyFolder

  • we set the type d to search for directory with a name of ‘MyFolder’

  • to search for regular files, you would use -type f



$ help echo

  • to provide information about other Bash built-in commands

$ find –help

  • for most other executable programs that are not built into the shell



$ man [command]

  • man (manual) pages to provide a detailed information of what a command does, its available options (or flags) and how to use it



$ whatis [command]

  • to display a concise, one-line description of a command directly from its manual (man) page.



$ alias ll=’ls -la’

  • to define a custom name for any command or sequence of commands

  • it creates temporary alias that lasts for your current terminal session

  • to make a command alias permanent, add it to your shell’s configuration file, that is ~/.bashrc

$ source ~/.bashrc

  • for the changes to take effect after adding in ~/.bashrc, either close and reopen the terminal or reload the configuration file using the above ‘source’ command

$ unalias ll

  • to remove the alias from your current session



$ exit

  • to end a shell session

$ logout

  • to terminate login shell
